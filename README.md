# This Week in AI - slides

Slide deck for O'Reilly's *This Week in AI* (June 15, 2026).

- **View the slides**: https://ykdojo.github.io/this-week-in-ai-slides/slides.html
- Self-contained single HTML file (`slides.html`) - no build step, no dependencies.

## Navigation

- Arrow keys / space / swipe to move between slides and reveal bullets
- The URL hash tracks position (e.g. `#5-2` = slide 5, 2 items revealed) so you can deep-link
